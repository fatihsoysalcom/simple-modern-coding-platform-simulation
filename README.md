# Simple Modern Coding Platform Simulation

This Python script simulates a basic Modern Coding Platform (MCP) by demonstrating a shared code repository, collaborative editing by multiple developers, and an automated CI/CD pipeline that reacts to code changes.

## Language

`python`

## How to Run

Save the code as `mcp_simulation.py` and run it from your terminal using: `python mcp_simulation.py`
